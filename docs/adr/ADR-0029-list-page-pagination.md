# ADR-0029：列表页分页——页码窗口、窄屏折叠与布局适配

**状态：** 已接受
**创建时间：** 2026-10-14

> **当前状态 / 核心结论：** 列表页分页为纯页码导航（当前页不可点高亮、首末页恒显），服务端按宽屏上限 ±3 环生成、窄屏由 CSS 折叠外圈，并显式放开 primer 的分页隐藏阶梯与列表容器最小宽。代码与测试均已落地；下一步为移动端实机核验窄屏观感。

---

## 背景

`primer-subset.css` 的分页隐藏阶梯（`.pagination>*{display:none}`，窄屏只留首末项、`≥768px` 才全显）是为「上一页 / 下一页」型分页设计的：站点改用纯页码导航后，该阶梯在 767px 以下把页码条压成只剩首末两页。同时列表容器 `min-width:360px` 在 375px 及以下视口未释放，造成横向溢出。

## 决策

1. **分页形态**：列表页分页为纯页码（无「上一页 / 下一页 / 末页」），当前页渲染为不可点的 `<span class="current" aria-current="page">`，首末页恒显；相邻页带 `rel="prev"` / `rel="next"` 与 `aria-label="Page N"`。
2. **页码窗口与省略**：服务端按宽屏上限「当前页 ±3 环」生成；被跳过的连续页恰好 1 页时直接列出该页，≥2 页才渲染省略号；页数不多时自然退化为完整序列。
3. **窄屏折叠**：`<768px` 折叠「距当前页 ≥2 环且外侧紧邻省略号」的页码。折叠只能从外向内连续进行——与首页 / 末页直接连续的页码段不可折叠，否则会出现跳号却无省略号的断档（如 `1 2 4 5`）。
4. **有意放开 primer 分页阶梯**：`.pagination>*` 统一为 `display:inline-block`，窄屏收窄改由按环数折叠承担，不沿用 primer 的隐藏式阶梯。
5. **窄屏释放列表容器最小宽**：`<768px` 下 `.SideNav` 取消 `min-width:360px`，避免 375px 及以下视口横向溢出。
   - 不做什么：不改每页篇数 `onePageListNum`、不改列表序（`list_order`）、不为窄屏引入 JS 重算页码。

## 后果

- **收益：** 分页在任何视口都可用且语义完整；窄屏可见页码数按屏宽收敛（宽屏最多 11 项、窄屏 7 项），不再出现只剩首末两页或连续两个省略号。
- **代价 / 权衡：** 页码条形状依赖「服务端渲染 + CSS 折叠」两级协作；渲染项形态由页码 / 省略号的扁平序列变为带 `ring` / `fold` 的结构化对象，模板与测试 fixture 须同步。
- **未解决风险：** 极窄视口（320px）下页码条的折行观感未经实机确认。

## 证据分档

| 假设 | 档位 | 取证方式 |
|------|------|----------|
| `plist.html` 的内联 `<style>` 在同特异性下能覆盖 primer 的 `.pagination>*{display:none}` | **已证实** | 静态取证：primer 由 `templates/base.html` 的 `<link>` 在 `<head>` 加载，`{% block style %}` 渲染于 `</head>` 之后，同特异性下后者胜出 |
| 窄屏折叠后页码条不超视口宽（不折行、不溢出） | 未证实（按最坏情况取保守分支） | 未做移动端实机截图；按折叠后 7 项 × 26px ≈ 182px、未折叠 11 项 × 26px ≈ 286px 与最小视口 320px 估算。若仍超宽，`inline-block` 会自然折行居中，属可接受的降级 |

## 实施位置

- 分页序列：`Gmeek.py#build_page_nav`（页码与省略号的扁平序列）
- 渲染项：`Gmeek.py#build_page_items`（附加 `ring` 与 `fold`）
- 列表页写入：`Gmeek.py#GMEEK.createPlistHtml`
- 模板与样式：`templates/plist.html`（分页块遍历渲染项、`.pagination>*` 覆盖、窄屏 `[data-ring]` 折叠、`.SideNav` 最小宽释放）

## 验证

- `pytest` 257 passed（`TestPageNumberPagination` 覆盖窗口 / 省略 / 边界、折叠标记，以及「与首页连续时不可折叠」的反例）。
- 端到端渲染矩阵核对 12 组 `total/current`：桌面与窄屏可见集均无「跳号却无省略号」断档（如 `20/10` 桌面为 `1 … 7 8 9 10 11 12 13 … 20`、窄屏为 `1 … 9 10 11 … 20`）。
- 评审：`docs/review/REV-0001-review-mobile-pagination.md`（0 critical / 0 high / 0 medium）。
