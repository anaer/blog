# ADR-0002：站点展示一致性——导航、时间与链接

**状态：** 提议中
**创建时间：** 2026-09-30

> **当前状态 / 核心结论：** 已定下展示层统一口径——上一篇=更早/下一篇=更晚且首末隐藏、全站固定 UTC+8、单页链接走 homeUrl、日期色标确定性生成；下一步进入 design 模式细化实施。

---

## 背景

线上实证：同一博客不同文章页的「上一篇」方向相反（全量构建按创建时间降序渲染，增量构建继承的是升序索引），末篇「下一篇」为随机文章（见 `post/199.html`），每次重建都会变；列表日期按运行环境本地时间（CI 为 UTC）而文章页按 +8 小时展示，跨日文章两处日期不一致；单页入口与 RSS 单页链接为根相对路径，在项目站 /blog/ 子路径下会 404（当前单页为空未暴露）；日期色标每次构建随机掷色，重复构建颜色漂移。

## 决策

1. **导航语义与排序统一**：导航序列为全部文章（含已关闭文章，不受置顶影响、单页不参与）按 `(createdAt, number)` 升序——上一篇=相邻更早、下一篇=相邻更晚；最早文章不显示上一篇、最新文章不显示下一篇；取消循环与随机；全量/增量两种构建共用同一序列（渲染批次内计算一次），并显式设置/清除上一篇、下一篇字段。
2. **时间展示统一 UTC+8**：底层时间戳一律按 UTC 正确换算（现状 `time.mktime` 按本机时区解释 UTC 时间，本地与 CI 产出的时间戳不同）；列表日期、文章页时间、自定义 `timestamp` 统一按 UTC+8 展示；RSS 保持 UTC 表示。
3. **链接修复**：单页入口与 RSS 单页条目统一用 `homeUrl` 前缀拼接；「# 号数字引用」的替换仅作用于正文代码块之外的文本，避免误伤 #123456 这类色值与代码内容。
4. **色标确定性生成**：日期标签颜色由 issue 编号或标题的稳定哈希派生，替换随机掷色；同一文章在任何构建中颜色一致。
5. **展示细节修复**：AI 摘要按纯文本转义输出；代码高亮样式仅在正文确实生成高亮块时加载（不再匹配正文中任意 highlight 字样）；标签页 URL hash 统一 encode/decode 处理。
   - 不做什么：不改列表页排序规则（置顶优先、按更新时间降序）；不改现有 hsl 配色区间。

## 后果

- **收益：** 全站导航语义一致、构建无随机噪声；本地与 CI 构建结果一致；单页功能可安全启用。
- **代价 / 权衡：** 已发布文章页的上一篇/下一篇方向会一次性翻转（统一到新口径）。

## 实施位置

- 导航：`Gmeek.py#nav_order`、`Gmeek.py#nav_neighbors`、`Gmeek.py#GMEEK.get_nav_keys`、`Gmeek.py#GMEEK.createPostHtml`
- 时间换算：`Gmeek.py#format_datetime_utc8`、`Gmeek.py#format_date_utc8`、`Gmeek.py#GMEEK.addOnePostJson`
- 引用替换：`Gmeek.py#replace_issue_refs`
- 色标：`Gmeek.py#deterministic_hue`
- 列表与 RSS：`Gmeek.py#GMEEK.createPlistHtml`、`Gmeek.py#GMEEK.createFeedXml`
- 模板：`templates/plist.html`（单页入口链接）、`templates/post.html`（摘要转义、高亮判定）、`templates/tag.html`（hash 编码）

## 验证

- 已实证（2026-09-30）：`post/100.html` 与 `post/152.html` 的上一篇方向相反；`post/199.html` 的下一篇为随机文章；跨日样例（20:00 UTC）在 UTC+8 下日期应 +1 天；`class="highlight"` 标记实存于转换产物。
- 待实施后（验收）：同一批文章分别经全量/增量构建，导航一致、首末隐藏正确、方向均为「上=更早」；列表日期与文章页时间均为 UTC+8；单页入口与 RSS 单页链接可达。
