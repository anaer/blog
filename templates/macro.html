{#- 统一图标渲染宏: 与 icons.py / 前端 renderIcon 保持同一风格(24x24 线性描边, Lucide 风)。 用法: 在模板顶部 import with context, 然后调用 icons.icon(name, size, cls, id, svg_class)。 - id: 需要 JS 定位时给 svg 加 id。 - svg_class: 追加到 svg 的 class(如列表项状态类 svgTop0/1)。 画布与描边宽度来自 icons.py, 经 Gmeek.py 注入 IconViewBox / IconStrokeWidth。 注意: Jinja 注释不可嵌套, 本注释内不再书写花括号井号标记。 -#} {% macro icon(name, size=16, cls='octicon', id=None, svg_class=None) -%} {%- set svgc = ((cls or '') ~ (' ' ~ svg_class if svg_class else '')) | trim -%} {{ IconList[name] | safe }} {%- endmacro %}
